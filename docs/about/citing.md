# Citing

## The software

If you use brainGL web in work that you publish, cite the paper that describes the glyphs and their implementation
in brainGL, on which the program is based, and the software itself.

> Böttger J, Schurade R, Jakobsen E, Schaefer A, Margulies DS (2014). Connexel visualization: a software
> implementation of glyphs and edge-bundling for dense connectivity data using brainGL. *Frontiers in
> Neuroscience* 8:15. [doi:10.3389/fnins.2014.00015](https://doi.org/10.3389/fnins.2014.00015)

For the software, use the `CITATION.cff` file at the root of the repository (GitHub and Zenodo read it): software
**brainGL web**, author Margulies, Daniel S., with the paper above as the preferred citation. No version, release date,
DOI or repository URL has been assigned yet; add them when you cite a specific release.
